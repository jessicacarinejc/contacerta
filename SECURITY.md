# Segurança

Relate vulnerabilidades de forma privada pelo recurso **Security Advisories** do GitHub.

Não publique documentos financeiros reais, credenciais, tokens, keystores, dados bancários ou informações pessoais em issues e pull requests.

## Controles implementados

- Content Security Policy no Tauri.
- Permissões Tauri mínimas.
- Persistência em armazenamento privado do aplicativo.
- Revisão humana antes do lançamento criado por OCR.
- Hash SHA-256 para identificação de documento.
- Sem logs do texto integral do documento.
