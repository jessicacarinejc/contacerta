# Contribuição

1. Crie uma branch a partir de `main`.
2. Use commits convencionais (`feat:`, `fix:`, `docs:`, `chore:`).
3. Execute `npm run check`.
4. Execute também `cargo fmt` e `cargo clippy` para alterações Rust.
5. Abra um pull request com impacto, validações e capturas das telas alteradas.

Alterações de regras financeiras devem incluir testes e explicar como evitam duplicidade ou inconsistência de saldo.
